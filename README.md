# Inventory Manager

## Project Description

Inventory Manager is a Python command-line program for managing a small inventory. The program allows users to view, add, update, remove, and search inventory items, as well as view an inventory summary.

## Features

The program provides the following menu options:

1. View inventory
2. Add an item
3. Update an item quantity
4. Remove an item
5. Search inventory
6. View inventory summary
7. Exit

## Inventory File Format

Inventory data is stored in `inventory.txt`.

Each item uses this format:

```text
Name|Category|Quantity
